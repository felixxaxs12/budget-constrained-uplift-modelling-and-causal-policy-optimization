# Data provenance

The analysis uses only the official unbiased Criteo Uplift v2.1 file:

- File: `criteo-uplift-v2.1.csv.gz`
- Official redirect: https://go.criteo.net/criteo-research-uplift-v2.1.csv.gz
- Dataset page and terms: https://ailab.criteo.com/criteo-uplift-prediction-dataset/
- Source-reported size: approximately 297 MB compressed
- Source-reported rows: 13,979,592

The dataset is licensed by Criteo under Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International. The repository will not mirror the raw file. The download stage will save it under `data/raw/` and record its actual byte size and SHA-256 checksum in a committed manifest.
